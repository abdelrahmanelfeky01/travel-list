# 🧳 Travel List — Packing List App

A React app to help you organize and track everything you need to pack before your next trip.

## ✨ Features
- ➕ Add items with quantity to your packing list
- ✅ Mark items as packed with a checkbox
- 🗑️ Delete individual items or clear the entire list
- 📊 Live stats showing packing progress percentage
- 🔃 Sort items by input order, name, or packed status
